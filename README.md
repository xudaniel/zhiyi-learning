<summary><b>第一次用 2.3：完成一个 5–8 分钟的学习单元</b></summary>

1. 从[课程全景](https://xudaniel.github.io/zhiyi-learning/#curriculum)选择一个重点，或从首页继续上次学习。
2. 读一段概念，确认它的使用条件。
3. 依次完成基础例题、条件变化、辨错练习和独立挑战；每次只显示一个任务。
4. 核对判断后展开真实课程摘录。答错可订正；首次结果和订正结果分别保留。
5. 独立挑战可以留一句自己的解释，完成后自动安排间隔复习。

手机、电脑均可使用。刷新后继续当前步骤，单元之间分别保存；完整分析练习仍在[分级实战](https://xudaniel.github.io/zhiyi-learning/#studio)。

<details>
<summary><b>分析报告怎样判断？</b></summary>

自动核对三个明确项目：事实判断、课程出处选择、判断边界选择。报告逐步指出需要修正的项目，列出课程解析并提供出处。

自由文字只检查「观察、理由、未决条件」是否填写，**不会把字数当作质量，也不会宣称已经理解其语义**。解释是否准确仍需对照课程，必要时请老师复核。规则通过不等于专业能力认证。

重新作答保留最近五份历史分析。可导出带拼音的文字报告，也可在[我的笔记](https://xudaniel.github.io/zhiyi-learning/#notes)备份完整学习记录。

</details>

<details>
<summary><b>路线为什么推荐这一课？</b></summary>

六项能力包括基本语言、四柱（sì zhù）定位、五行（wǔ xíng）清点、月份条件、关系层次和口诀查法。页面显示前置知识和推荐原因。

能力状态来自入门诊断、短课作答、复习及已提交训练，分为「待练习／需要巩固／初步理解／练习稳定」。只浏览页面或完成示范不会计为独立能力通过；最近的错误会提醒回练。

每日计划在当天首次打开时固定，避免学习目标随作答不断移动。概念自测正确、对应示范完成或训练提交，才计入当天相应活动；没有到期题目时会显示「今日无到期项」。

<summary><b>怎样保存、迁移和离线使用？</b></summary>

- 在[我的笔记](https://xudaniel.github.io/zhiyi-learning/#notes)导出学习记录，备份包含新旧课程进度、连续学习的首次与订正记录、单元复述、助教草稿、分析草稿与历史、诊断、每日计划、收藏和复习安排。

- 进度只保存在当前浏览器，不自动上传或跨设备同步。更换设备、浏览器或网址时，用备份迁移。
- 下载 [docs/index.html](https://github.com/xudaniel/zhiyi-learning/raw/refs/heads/main/docs/index.html)，双击后输入课程密码即可离线学习。
- 页面顶部提供「锁定课程」。独立打开新标签页需要密码；会话存储不可用时刷新也需要再次输入。

完整发布页面经过密码加密。仓库源码与历史版本仍公开可访问，此入口不等同于服务端账号权限。

开发环境为 Node.js 22+：

```sh
pnpm install --frozen-lockfile
pnpm run build:check
# 通过本机环境设置 ZHIYI_COURSE_PASSWORD 后构建与测试
pnpm run build
pnpm test
pnpm exec playwright install chromium
pnpm run test:e2e
```

构建和浏览器测试从 `ZHIYI_COURSE_PASSWORD` 环境变量读取密码，无默认值；不要提交真实密码。`build:check` 检查已发布文件与源码是否一致，提供密码时还会解密核对全文。CI 先检查已提交页面，再用专用测试密码构建临时页面进行回归，该页面不会发布。

可设 `PLAYWRIGHT_CHANNEL=chrome` 使用本机 Chrome，或设 `APP_URL` 验证指定网址。测试使用独立浏览器，不读取个人记录。

`src/curriculum.json` 管理 10 个单元及 40 道题，`src/journey-core.js` 与 `src/journey.js` 管理连续学习和备份；`server/` 与 `api/tutor.js` 提供课程助教服务。`src/mastery-core.js` 维护原有的训练、诊断、推荐与知识关系；`src/mastery.js` 实现学习界面，`src/mastery.css` 提供布局。基础课程与既有练习保留在原模块；`src/pinyin.js` 负责逐次注音；`scripts/seal.mjs` 加密完整页面。GitHub Pages 从 `main` 的 `/docs` 发布。

**Developer: Daniel Xu**

Original software is licensed under the [MIT License](LICENSE), with copyright attributed to Daniel Xu. Please also read the [separate rights statement for course content and handout images](LICENSING.md).

Zhiyi is an interactive learning space organized around Teacher Shi's existing course materials. **Start from zero with 10 learning units and 40 exercises with course citations, connecting concepts, answers, feedback and review in one continuous learning path.**

**[Start continuous learning →](https://xudaniel.github.io/zhiyi-learning/#journey)** · [Choose a unit](https://xudaniel.github.io/zhiyi-learning/#curriculum) · [Practice analysis](https://xudaniel.github.io/zhiyi-learning/#studio) · [View your learning path](https://xudaniel.github.io/zhiyi-learning/#path) · [Explore the knowledge map](https://xudaniel.github.io/zhiyi-learning/#knowledge)

All learning areas require a course password; obtain it from the course owner. Refreshing the same tab can resume your session. Use “锁定课程” (Lock course) to lock it again; your notes and progress are retained.

**New in 2.3:** This README now provides complete Chinese and English guides, with Chinese first and links between languages. The software and course materials retain their separate licensing scopes. The app interface and lessons are in Chinese; the live AI service is still awaiting connection. [Read the 2.3 release notes](docs/v2.3-release.md).

<details open>
<summary><b>Your first session in 2.3: complete a 5–8 minute unit</b></summary>

1. Choose a focus in the [curriculum overview](https://xudaniel.github.io/zhiyi-learning/#curriculum), or resume your last unit from the home page.
2. Read a short concept explanation and check the conditions under which it applies.
3. Work through a basic example, a changed condition, an error-spotting exercise and an independent challenge. One task appears at a time.
4. Check your answer, then expand the actual course excerpt. You can correct a mistake; the first answer and the correction are kept separately.
5. Add an explanation in your own words to the independent challenge if you wish. Completing the unit schedules spaced review.

Use a phone or a computer. Refreshing resumes the current step, and each unit saves its own progress. Full analysis exercises remain available in the [practice studio](https://xudaniel.github.io/zhiyi-learning/#studio).

</details>

The live AI service is not connected yet.** The page displays “AI 服务待连接” (AI service awaiting connection). Local preset answers are not presented as live AI responses. The existing [course Q&A](https://xudaniel.github.io/zhiyi-learning/#ask) still works offline.

Once the service is configured, the tutor is designed to identify what you have explained clearly, what needs correction and what is missing, followed by a guiding question. The server selects only course passages included in this version and checks citation IDs and exact source wording. Missing evidence or mismatched citations remain unverified.

A submission sends only the current text, topic and question ID; the server then selects related course passages. Other notes are not uploaded automatically, and model credentials stay on the server. Generated feedback still needs checking against the course: a matching citation does not establish that the reasoning is correct.

<details>
<summary><b>How are analysis reports assessed?</b></summary>

The app automatically checks three explicit items: the factual judgment, the selected course source and the selected limit of that judgment. The report identifies what to correct at each step, with a course explanation and citation.

For free text, it only checks whether “observation,” “reason” and “unresolved conditions” have been filled in. **It does not treat word count as quality or claim to understand the meaning of your explanation.** Check accuracy against the course and, where needed, ask the teacher to review it. Passing the rule checks is not professional certification.

Retrying keeps the five most recent analysis histories. Export a text report with pinyin, or back up your complete learning records in [My notes](https://xudaniel.github.io/zhiyi-learning/#notes).

</details>

<details>
<summary><b>Why does the learning path recommend this lesson?</b></summary>

The six skills cover basic terminology, locating the Four Pillars (sì zhù), counting the Five Elements (wǔ xíng), month conditions, relationship levels and applying course mnemonics. The page shows prerequisites and the reason for each recommendation.

Skill status comes from the entry diagnostic, short-lesson answers, reviews and submitted practice. The four states are “not practiced,” “needs reinforcement,” “initial understanding” and “consistent practice.” Browsing a page or completing a worked example does not count as passing independent practice; recent mistakes prompt further review.

The daily plan is fixed when first opened that day, so its targets do not keep changing as you answer. A correct concept check, a completed matching demonstration or a submitted exercise counts toward the corresponding activity. If nothing is due, the app says so.

<summary><b>How do I save, migrate and use the course offline?</b></summary>

- Export learning records from [My notes](https://xudaniel.github.io/zhiyi-learning/#notes). Backups include old and new course progress, first and corrected unit answers, unit explanations, tutor drafts, analysis drafts and history, diagnostics, daily plans, favorites and review schedules.
- Version 1.x backups can still be restored. Existing nonempty course notes take priority; newer practice data is merged by update time, so an older backup does not replace a newer draft.
- Progress is stored in the current browser. It is not automatically uploaded or synced across devices. Use a backup when changing devices, browsers or site addresses.
- Download [docs/index.html](https://github.com/xudaniel/zhiyi-learning/raw/refs/heads/main/docs/index.html), open it locally and enter the course password to study offline.
- Use “锁定课程” (Lock course) at the top of the page. A separately opened tab requires the password; refreshing also requires it when session storage is unavailable.

The complete published page is encrypted with the course password. Repository source files and historical versions are still publicly accessible; the password entrance is not equivalent to server-side account authorization.

```sh
pnpm install --frozen-lockfile
pnpm run build:check
# Set ZHIYI_COURSE_PASSWORD in your local environment before building and testing
pnpm run build
pnpm test
pnpm exec playwright install chromium
pnpm run test:e2e
```

The build and browser tests read `ZHIYI_COURSE_PASSWORD` from the environment, with no default. Do not commit the actual password. `build:check` verifies that the published file matches the source; if a password is supplied, it also decrypts and checks the complete content. CI first checks the committed page, then builds a temporary page with a dedicated test password for regression tests. That test page is not published.

Set `PLAYWRIGHT_CHANNEL=chrome` to use a locally installed Chrome browser, or `APP_URL` to verify a specific URL. Tests use an isolated browser and do not read personal learning records.

`src/curriculum.json` defines the 10 units and 40 questions. `src/journey-core.js` and `src/journey.js` handle continuous learning and backups; `server/` and `api/tutor.js` implement the tutor service. `src/mastery-core.js` manages existing practice, diagnostics, recommendations and knowledge relationships; `src/mastery.js` implements the learning interface, with layout in `src/mastery.css`. Foundational lessons and earlier exercises remain in their existing modules. `src/pinyin.js` handles repeated pronunciation annotations, and `scripts/seal.mjs` encrypts the complete page. GitHub Pages publishes from `/docs` on `main`.
