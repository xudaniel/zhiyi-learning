<details open>
<summary><b>第一次用 2.0：走完一条完整学习路径</b></summary>

1. 打开[学习路线](https://xudaniel.github.io/zhiyi-learning/#path)，完成六个小判断。也可以跳过，先按基础顺序学习。
2. 在今天的安排里读一个概念，并完成对应自测。
3. 进入[分级实战](https://xudaniel.github.io/zhiyi-learning/#studio)，选择案例和层级。
4. 先看「完整示范」，再用「渐退提示」按步练习，最后进入「独立分析」。
5. 独立分析一次提交五步，逐项填写判断、观察、课程依据、适用理由与未决条件。
6. 对照报告回看偏差，从报告直接跳到知识节点或对应基础课，然后重新作答。

两张教学组合不是个人生日命盘。每个案例、每个层级有独立草稿和进度，刷新后可以继续。

</details>

<details>
<summary><b>分析报告怎样判断？</b></summary>

自动核对三个明确项目：事实判断、课程出处选择、判断边界选择。报告逐步指出需要修正的项目，列出课程解析并提供出处。

自由文字只检查「观察、理由、未决条件」是否填写，**不会把字数当作质量，也不会宣称已经理解其语义**。解释是否准确仍需对照课程，必要时请老师复核。规则通过不等于专业能力认证。

重新作答保留最近五份历史分析。可导出带拼音的文字报告，也可在[我的笔记](https://xudaniel.github.io/zhiyi-learning/#notes)备份完整学习记录。

</details>

<details>
<summary><b>路线为什么推荐这一课？</b></summary>

六项能力包括基本语言、四柱（sì zhù）定位、五行（wǔ xíng）清点、月份条件、关系层次和口诀查法。页面显示前置知识和推荐原因。

能力状态来自入门诊断、短课作答、复习及已提交训练，分为「待练习／需要巩固／初步理解／练习稳定」。只浏览页面或完成示范不会计为独立能力通过；最近的错误会提醒回练。

每日计划在当天首次打开时固定，避免学习目标随作答不断移动。概念自测正确、对应示范完成或训练提交，才计入当天相应活动；没有到期题目时会显示「今日无到期项」。

</details>

- [关系与事件的区别](https://xudaniel.github.io/zhiyi-learning/#knowledge/clashes)

文昌（wén chāng）诀（jué）已对照讲义第 77 页，提供原图与逐次注音文字。其他出处保留课程摘录或已有讲稿总结的来源类型。缺乏依据的规则保持待核，不补写为施老师结论。

<details>
<summary><b>怎样保存、迁移和离线使用？</b></summary>

- 在[我的笔记](https://xudaniel.github.io/zhiyi-learning/#notes)导出学习记录，备份包含新旧课程进度、分析草稿与历史、诊断、每日计划、收藏和复习安排。
- 1.x 备份仍可恢复。原有非空课程笔记优先保留；新增训练按更新时间合并，较旧备份不会替换较新的草稿。
- 进度只保存在当前浏览器，不自动上传或跨设备同步。更换设备、浏览器或网址时，用备份迁移。
- 下载 [docs/index.html](https://github.com/xudaniel/zhiyi-learning/raw/refs/heads/main/docs/index.html)，双击后输入课程密码即可离线学习。
- 页面顶部提供「锁定课程」。独立打开新标签页需要密码；会话存储不可用时刷新也需要再次输入。

完整发布页面经过密码加密。仓库源码与历史版本仍公开可访问，此入口不等同于服务端账号权限。

</details>

开发环境为 Node.js 22+：

```sh
pnpm install --frozen-lockfile
pnpm run build:check
# 通过本机环境设置 ZHIYI_COURSE_PASSWORD 后构建与测试
pnpm run build
pnpm test
pnpm exec playwright install chromium
pnpm run test:e2e
```

构建和浏览器测试从 `ZHIYI_COURSE_PASSWORD` 环境变量读取密码，无默认值；不要提交真实密码。`build:check` 检查已发布文件与源码是否一致，提供密码时还会解密核对全文。CI 先检查已提交页面，再用专用测试密码构建临时页面进行回归，该页面不会发布。

可设 `PLAYWRIGHT_CHANNEL=chrome` 使用本机 Chrome，或设 `APP_URL` 验证指定网址。测试使用独立浏览器，不读取个人记录。

`src/mastery-core.js` 维护 2.0 的训练、诊断、推荐与知识关系；`src/mastery.js` 实现学习界面，`src/mastery.css` 提供布局。基础课程与既有练习保留在原模块；`src/pinyin.js` 负责逐次注音；`scripts/seal.mjs` 加密完整页面。GitHub Pages 从 `main` 的 `/docs` 发布。
