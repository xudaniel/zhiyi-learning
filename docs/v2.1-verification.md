开发者 Daniel Xu。

## 本地验证完成

- 29 项逻辑测试通过：原课程、分级实战、备份与拼音；10 个新单元的 40 道题；课程引用；首次与订正记录；助教服务的访问校验、长度限制、并发、频率和失败状态。
- 6 组浏览器流程通过：密码入口、原学习流程、课程扩展、2.0 分级实战、2.1 连续学习、课程助教。
- 新增深链接同样先进入密码入口；错误密码、伪造状态、独立标签页、刷新、重新锁定和存储不可用场景仍通过。
- 新题逐个作答并检查原文引用，覆盖错误订正、重复提交防护、刷新续学、复习日期、导出恢复与旧备份合并。
- 助教界面实际连接服务处理函数进行测试，模型响应由测试替身提供；验证引用不符时转待核、限流、取消、草稿恢复和安全显示。
- 320、390、1440 像素布局检查通过；课程全景和手机连续学习截图已检查。检查目标难字逐次拼音，无嵌套注音。
- 构建产物与当前源码一致，提供课程密码后可解密回完整页面。服务端构建通过。

运行方式：`pnpm test`、`pnpm run test:e2e`、`pnpm run build:check`。浏览器测试使用隔离环境；课程密码由环境变量提供。
