## [Story · 2.1 · 方向 1] 连续学习：概念、动手、反馈、复习在同一路径完成

[GitHub Issue #15](https://github.com/xudaniel/zhiyi-learning/issues/15)

## 用户故事
作为从零学习的学员，我希望一次只专注一个小任务，在同一页面读概念、作答、看依据并继续练习，随时离开后能接着学。

## 验收标准
- [ ] 首页主入口进入连续学习；一个单元串起概念、基础例题、条件变化、辨错、独立挑战及复习安排。
- [ ] 点击选择、配对或排序完成初阶任务，初阶不要求填写整份分析表；独立挑战允许简短复述。
- [ ] 答案揭晓后显示课程依据及适用条件；错误可重试，记录首次作答与之后的订正。
- [ ] 刷新继续当前步骤；换单元不覆盖进度；新记录可导出、恢复并兼容旧备份。
- [ ] 通过后接入已有间隔复习，重复点按钮不重复增加作答。
- [ ] 320 / 390 / 1440 宽度可用，键盘可操作，难字每次出现有拼音。

## 实施顺序
用户指定 1 → 3 → 2，本项先实施，再扩充题库。

## [Story · 2.1 · 方向 3] 课程练习成组扩充与可追溯覆盖清单

[GitHub Issue #16](https://github.com/xudaniel/zhiyi-learning/issues/16)

## 用户故事
作为希望学会迁移方法的学员，我希望围绕同一知识点练基础、变式、辨错和独立挑战，并随时查看课程依据与尚未覆盖的范围。

## 验收标准
- [ ] 至少 8 个可学习单元，每单元 4 类练习；覆盖基础语言、四柱位置、五行清点、月份条件、关系层次、口诀及方位。
- [ ] 每道题有稳定 ID、课程出处、答案说明和适用边界；变式明确改变了哪个条件。
- [ ] 展示易经基础、四柱分析、风水方位的覆盖清单；完整排盘、待核口诀与住宅布局等缺失内容明确待补。
- [ ] 区分课程摘录、既有总结与根据课程设计的教学练习；不将教学组合当真实生日命盘。
- [ ] 题库筛选及单元深链接有效；题目进入连续学习及既有复习系统。
- [ ] 校验全部引用能在现有课程中找到；待核内容不作为确定结论。

## [Story · 2.1 · 方向 2] 有课程依据的 AI 助教：解释反馈、追问与可靠引用

[GitHub Issue #17](https://github.com/xudaniel/zhiyi-learning/issues/17)

## 用户故事
作为学员，我希望提交自己的理解后，助教能根据实际课程指出已说清的内容、缺失条件和需要修正的推理，并给一个可继续思考的问题。

## 验收标准
- [ ] 从练习或助教页面提交短问题、解释及所选课程主题，返回语义反馈与追问。
- [ ] 服务端只检索版本内真实课程摘录；回答的引用 ID 和原文片段必须通过校验。
- [ ] 不足以支持结论时明确待核；不冒充施老师，不生成确定个人预测。
- [ ] API 凭据仅在服务端；校验来源、访问凭证、输入长度、请求频率和超时，不公开密钥。
- [ ] 明示发送范围，不默认上传全部笔记或个人资料；错误、限流、离线和服务未配置有准确状态。
- [ ] 有真实服务可用时完成在线模型验证；若配置缺失，保留本项开启，明确待配置，不能把预设规则答复说成 AI。
- [ ] 助教返回内容安全显示、逐次拼音；课堂原文与生成的教学反馈分开展示。

## 外部依赖
需配置可部署的服务端与模型访问。前两项继续实施，接入选择已向课程所有者确认中。
