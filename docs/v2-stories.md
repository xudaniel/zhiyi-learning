# 知易 2.0 · 产品规格与用户故事

开发者：Daniel Xu

## 问题与目标

现有课程已能帮助初学者认字、做选择题和跟随案例，但学习者仍需要自己组织观察、依据和判断边界。2.0 将分级实战作为主线，个人学习路线提供配套，知识地图贯穿课程依据。

验收目标：两个案例各有三种训练方式；学习者可独立提交五步分析；所有反馈均能回到课程出处；六项能力根据实际作答更新；新旧记录可备份恢复；各主要产品入口清晰标明开发者 Daniel Xu。

## 交付顺序

1. [分级实战与分析报告 #11](https://github.com/xudaniel/zhiyi-learning/issues/11)：完整示范 → 渐退提示 → 独立分析。按步骤核对事实、来源和判断边界，保存原始表达与重练历史。
2. [个人路线与每日计划 #12](https://github.com/xudaniel/zhiyi-learning/issues/12)：六项诊断、前置关系、推荐原因、概念自测、案例应用和到期复习。浏览页面不会增加能力状态。
3. [课程知识地图 #13](https://github.com/xudaniel/zhiyi-learning/issues/13)：13 个知识节点，支持检索、主题筛选、相关概念、适用条件、常见误用和出处查看。
4. [专业界面与正式发布 #14](https://github.com/xudaniel/zhiyi-learning/issues/14)：重组首页导航，完善署名、关于说明、分析报告、备份元信息、README 和 v2.0.0 发布。

## 必须满足

- 每个案例每个层级独立保存草稿；演示不计为独立能力通过。渐退练习可主动查看提示；独立训练在提交后统一反馈。
- 事实、依据选择、边界选择使用明确规则核对；自由文字仅检查三项表达是否填写，始终保留“语义待复核”说明。不会把字数当作分析质量。
- 学习状态包含待练习、需要巩固、初步理解、练习稳定，并展示依据。推荐可跳过，不强制锁住课程。
- 日计划在当天首次打开时固定，避免完成一项后目标自动变化；概念自测答对、训练提交或示范完成才计入相应活动。
- 每个新页面、反馈、选择项和笔记预览都沿用逐次拼音。
- 既有课程内容、密码、进度键名、离线能力和传统解释边界保留。新增数据导入按允许字段校验，旧备份不会覆盖较新的训练草稿。

## 完成判据与测量

发布前对两个案例的全部层级、独立反馈、六题诊断、推荐变化、知识深链接、待核节点、恶意文本、刷新恢复、旧备份合并及移动布局进行自动检查。上线后核对真实发布文件与密码流程。

产品中的“规则核对通过”仅表示本次练习的结构化答案正确。独立说明是否准确，需要学习者对照课程或请老师复核。长期教学效果没有现成数据，后续可用独立复述质量评估，不虚构通过率或学习提升幅度。

## 本版边界

不补写缺少课程依据的命理算法，不自动排真实生日命盘，不提供个人事件预测或住宅布局结论。维持本地记录；账号、云同步和服务端权限属于后续独立工作。公开仓库及历史版本仍可访问。
