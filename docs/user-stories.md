## Story 1：每次出现都能看懂读音

作为从零学习施老师课程的学员，我希望十天干、十二地支和课程中的难字每次出现都有带声调的拼音，这样不必记住上一页的发音，也不用暂停学习查字。

验收标准：
- 十天干：甲 jiǎ、乙 yǐ、丙 bǐng、丁 dīng、戊 wù、己 jǐ、庚 gēng、辛 xīn、壬 rén、癸 guǐ。
- 十二地支：子 zǐ、丑 chǒu、寅 yín、卯 mǎo、辰 chén、巳 sì、午 wǔ、未 wèi、申 shēn、酉 yǒu、戌 xū、亥 hài。
- 初版难字词表覆盖爻 yáo、卦 guà、乾 qián（乾坤、乾造）、坤 kūn、彖 tuàn、筮 shì、煞 shà（神煞）、禄 lù、驿 yì、魁 kuí、罡 gāng、庚辛壬癸、戊己巳已等易混字，以及实际课程里筛出的难字。
- 正文、标题、重复出现的词、课程卡片、天干翻卡正反面、四柱、练习题、答题反馈、错题、搜索结果、课程资料和导航都标注，不只第一次出现时标注。
- 正文与按钮优先使用汉字上方的拼音；原生下拉选项显示“汉字（拼音）”，选项值保持汉字。
- 用户笔记及默写输入保留原始汉字，在输入框附近显示同步拼音预览；不把拼音写入答案或备份记录。
- 原讲义图片保持原貌，附完整可读、可注音的文字版，用户无需放大图片猜读音。
- 多音字按词语语境处理，不把“已经”的已读成巳，也不把“干掉”的干读成天干的干。

## Story 2：拼音不能破坏施老师教法和已有进度

作为已有学习记录的学员，我希望加入拼音后，施老师教法8步、12节短课、错题、笔记及备份仍然正常。

验收标准：
- 保持既有课程ID和浏览器存储键，旧学习记录可继续读取。
- 每次翻卡、选择答案、切换课程、检索原文和动态反馈后都补上拼音，不出现重复嵌套注音。
- 默写、选择题与五行分类仍用原始汉字判题，注音不影响选项值。
- 手机窄屏和电脑布局不遮字、不横向溢出；键盘可操作，拼音和汉字均可辨读。
- 自动检查覆盖所有页面及动态状态，核对“戊、己、巳、已、戌、戍”的声调和区分。
- 离线单文件版本仍可使用，学习记录可以导出、恢复。

## Story 3：先有 Issues，再发布可追踪的在线版本

作为项目所有者，我希望先在 GitHub 记录故事和验收标准，再提交实现与测试，并得到可以实际打开的线上链接。

验收标准：
- 目标仓库确认后先建立上述三项 Issues；实现提交引用相应 Issue。
- 不覆盖现有线上产品或用户未提交的工作，使用明确的独立目录或仓库。
- 保存可维护的源码、构建步骤、发音词表和测试；不只提交一份无法维护的输出文件。
- 上线仅使用适合该站点访问范围的课程内容；公开版不包含原稿中的个人婚姻、家庭与命盘描述。
- 本地测试通过后推送，确认远端提交与发布状态，再对线上页面执行浏览器验证。
- Issues 留下验收结果与线上地址，完成后关闭；失败则记录实际阻塞，不能把“已推送”写成“已上线”。
