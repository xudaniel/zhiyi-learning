# 完整课程密码入口 · 1.0.2

Story / [Issue #10](https://github.com/xudaniel/zhiyi-learning/issues/10) 先于实现建立。

作为课程使用者，我希望进入知易时先输入课程密码，验证成功后才能查看和使用完整课程；离开时可以重新锁定，并保留学习进度。

验收范围：

- 任意课程直达链接首先显示密码入口，包括课程、案例、练习、答疑、笔记、搜索与资料。
- 正确密码解锁；空密码和错误密码给出明确提示，支持键盘提交和显示／隐藏输入。
- 完整课程页面采用密码派生密钥加密，解锁前没有课程正文、导航或讲义图片。
- 同一标签页刷新自动恢复；“锁定课程”清除本标签页的解锁状态。独立打开新标签页需要密码。
- 不改变原学习记录的存储位置，原笔记、答题、收藏和备份继续使用。
- 在线与离线单文件一致；移动布局和完整学习流程通过回归验证。

实现：Web Crypto、PBKDF2-SHA-256（210,000 次）、AES-256-GCM。每次生成使用新的随机盐与随机 nonce。密码由构建环境传入，不写入源码、页面或公开文档。解锁密钥仅保存在本标签页会话中；浏览器禁止会话存储时仍可解锁，但刷新需要再次输入。

范围：这是静态站点的课程入口。仓库源码及历史版本仍公开可访问，简短共享密码不能替代有服务端权限控制的账号系统；本次不改变仓库可见性或历史。

验证：`tests/access.test.mjs` 检查加密还原、错误密码、篡改检测与发布页面内容；`tests/access-e2e.mjs` 检查全部入口、重新锁定、浏览器返回、标签页隔离、进度兼容及移动布局。原有两套浏览器流程继续覆盖全部教学功能。
