# 拼音标注约定

所有天干地支字符、已收入词表的难字，以及指定的易学词语每次出现都注音。正文使用 ruby/rt；原生选项采用括号拼音；输入框不写入拼音，旁边展示实时读音。存储、搜索和判题继续处理原始汉字。

声调用字典读音，不进行口语连读变调。先匹配最长词语，再回退到单字。例：天干 gān、干掉 gàn；但课程中的“水都快干掉了”表示干涸，使用 gān。乾坤 qián、乾燥 gān；孩子的子轻声 zi、干支中的子 zǐ；将星 jiàng；易传 zhuàn；寡宿 sù。

初版词表包括十天干、十二地支、戊己巳已戌戍易混字，以及爻、彖、筮、乾坤、神煞、魁罡、驿马、禄、旬、纳音、羲、藤蔓、毛坯等。对未收录的任意生僻字不猜读音；需要扩充时更新词表及语境测试。
