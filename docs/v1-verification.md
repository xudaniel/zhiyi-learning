# 知易 1.0 验证记录

## 已验证

- 11 项自动化逻辑检查：两张教学组合的五行计数和文昌位置；来源摘录定位；24 张听读卡；复习间隔；备份合并；13 条课程问答；逐次拼音与多音字；公开资料范围。
- 新功能浏览器检查：两例各 5 步答题、下一步门槛、作答历史、切换/刷新续学、复述、来源弹窗与原页、月份对照、复习排程、收藏/待核、导出恢复和旧版合并。
- 原有流程回归：12 节课程、8 步教法、7 类互动练习、错题本、笔记、全文搜索、文昌原页、学习记录迁移。
- 在 320、390、1440 像素宽度检查逐次注音、无嵌套拼音、无页面横向溢出；原页弹窗可用 Escape 关闭。
- 输入、笔记及待核文本保持原始汉字，显示时转义，不执行输入的 HTML。

## 语音验证的边界

浏览器测试模拟中文语音、无中文语音、开始、错误及停止事件；不代表每台设备都已安装中文语音，也不验证声学发音质量。真实朗读依赖设备与浏览器提供的中文声音，页面始终保留拼音和文字练习。没有使用或仿制老师声音。

## 复现

运行 `pnpm test` 与 `pnpm run test:e2e`。线上验证时设置 `APP_URL=https://xudaniel.github.io/zhiyi-learning/`；检查使用独立浏览器，不读取用户真实学习记录。

在线部署与正式发布以 GitHub Actions 记录及 v1.0.0 Release 为准。
