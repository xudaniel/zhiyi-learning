# 知易 1.0：五项用户故事

方向：案例教学为核心（2项），零基础陪练配套（2项），课程依据保证可靠（1项）。先建立故事与 Issues，再实现、验证、推送；随后单独更新可交互 README 并再次推送，最后发布 v1.0.0。

## 1. 跟着案例完成整条分析路径

作为初学者，我希望围绕一张教学四柱逐步作答，完成后能回看“我怎么想、为什么错、课程依据是什么”，而不只是看答案。

验收标准：
- [x] 提供至少两张标注为教学组合的四柱，分别保存进度，不套用真实人物生日。
- [x] 每例覆盖日元、五行清点、月份、地支关系、文昌起查；每步先作答，提交后才展示解析。
- [x] 正确后才进入下一步，错误尝试记录为对应薄弱点；切换案例及刷新可恢复。
- [x] 完成后显示完整推理路径、答题记录与可编辑复述。
- [x] 每步有课程来源入口，保持逐次拼音标注。

## 2. 在月份对照中理解条件变化

作为学习者，我希望把施老师讲过的农历二月壬水与五六月壬水并排比较，先预测再看讲解，理解为什么同一日元会有不同讨论。

验收标准：
- [x] 两个课程情境明确区分；月份沿用课程称呼，不假装独立换算节气。
- [x] 先回答变化的原因，再揭示冷暖、水量、所需及条件的对照。
- [x] 把老师原话/既有总结与 App 的教学整理分开标注；每个对照有证据入口。
- [x] 不把“缺什么就补什么”或固定喜忌套用于所有壬水。
- [x] 保存判断、复述和完成状态；对照是课程案例学习，不生成完整旺衰或住宅判断。

## 3. 听读与易混字专项练习

作为不熟悉读音和字形的初学者，我希望能逐字听读干支、对比戊戌戍与己巳已，并用针对练习巩固。

验收标准：
- [x] 覆盖十天干、十二地支及两组易混字，始终显示拼音。
- [x] 浏览器有中文朗读语音时可点读，提供播放/结束/失败状态；没有语音时明确提示，保留文字练习。
- [x] 至少包含读音辨字练习，提交后显示读音、字形区分与必要的五行或类别说明。
- [x] 朗读使用原始汉字和语境，不把页面拼音、菜单等一起读出；不使用老师声音、不声称老师本人配音。
- [x] 错误进入专项复习记录，正确和错误反馈继续逐次注音。

## 4. 根据薄弱点安排今天的复习

作为持续学习者，我希望系统根据真实答题记录安排今天该练什么，并在之后再次检查，而不是只增加完成百分比。

验收标准：
- [x] 汇总案例、短课和听读练习里的知识点表现，显示尝试数和薄弱点。
- [x] 错题立即可复习；答对后按1、3、7天的简单间隔安排下次复习，并说明这是练习安排规则。
- [x] 同一道题不能通过重复点击刷次数；同一天反复答对不连续跨越复习阶段。
- [x] 提供“现在到期”“未来安排”及对应练习入口，没有记录时给出起步建议。
- [x] 复习记录、案例及复述随现有学习备份导出/恢复，旧版本备份仍可使用。

## 5. 带课程证据的概念答疑

作为使用施老师方法学习的学员，我希望对常见疑问得到可追溯的解释，遇到课程没有给出的规则能明确留下待核问题。

验收标准：
- [x] 至少12条课程内常见问答，可按问题或术语搜索，明确为本地整理问答而非实时生成式 AI。
- [x] 每条解释附来源名称、位置和可查看的摘录；区分原话、讲稿总结、App教学整理及待核内容。
- [x] 不匹配的问题不套用无关答案，展示“现有问答未覆盖”并允许保存到个人待核清单。
- [x] 文昌规则链接原页；天乙口诀存在未定口径时不自动合并成确定算法。
- [x] 收藏/待核问题可保存并随备份迁移；来源跳转、拼音和移动端可用。
