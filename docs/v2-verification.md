# 知易 2.0 验证记录

开发者 Daniel Xu

自动验证入口：`pnpm test` 与 `pnpm run test:e2e`。

## 验证范围

- 20 项逻辑检查：原有读音、案例、出处、复习与备份；加密还原及篡改检测；新增训练反馈、缺项识别、诊断与推荐、知识连接、数据校验与开发者署名。
- 密码流程：全部课程入口、空／错／正确密码、刷新、主动锁定、返回、独立标签页、旧记录保留、会话存储受限。
- 原有课程回归：12 节短课、8 步基础教法、全部练习、两条原版案例、月份对照、听读状态、答疑、复习和备份。
- 2.0 流程：两个案例全部三层训练、提示记录、独立提交、错误与缺项反馈、重练历史、草稿恢复和报告导出。
- 学习路线：六项诊断、未完成提示、跳过／重做、刷新恢复、今日概念自测与复习登记。
- 知识地图：搜索、主题筛选、空结果、节点深链接、待核内容、讲义图片、返回分析。
- 数据与布局：完整备份恢复、旧版合并、恶意文本转义、逐次拼音、开发者署名和 320／390／1440px 布局。

## 实际边界

规则检查验证结构化选择，文字检查验证是否填写，不自动判断自由表达的语义。语音状态使用模拟接口验证，真实朗读依赖设备中文语音。浏览器回归使用 Chromium，不表示已逐一验证所有浏览器。

发布时以 GitHub Actions 的对应提交结果及 Pages 部署结果为准。正式网页应与提交的加密页面逐字节一致，并在真实网址复核解锁与新页面入口。
